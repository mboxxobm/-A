# Public backup manifest

Created: 2026-10-03 (Asia/Tokyo)

This backup is prepared for the public repository `mboxxobm/-A`.

## Included

- Character illustrations, face cards, face crops, contact sheets, and the 4-cut/full-body character sets.
- Transparent character cutouts.
- Character settings, dual-mode settings, visual direction notes, gender-variant notes, and generation prompt logs.
- Blender prototype source, `.blend` file, and preview image.
- Public site output needed to preview the current site.
- A project history summary describing the character/site decisions represented by the local files.

## Excluded from the public backup

- API keys, credentials, private tokens, and environment files.
- `.DS_Store`, build caches, temporary files, and internal Codex/OpenAI hosting configuration.
- Sponsor proposal decks and campaign/personal-data documents until their public-release status is confirmed.
- Redundant tar/zip bundles that duplicate the included files.
- Raw ChatGPT conversation history. The local project files and prompt logs are included; the full chat transcript is not available as a local export.

## Scope note

The destination repository is public. This manifest intentionally records the public-safe scope rather than silently publishing every local file. Sensitive or private materials can be added later only after the repository is made private or those files are explicitly approved for public release.
