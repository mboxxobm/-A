## 固定した要素

- 吟遊詩人型の明るく人を巻き込む印象
- 淡いブラウン系の髪と、ピンクの差し色
- 音楽を媒介に人や話題をつなぐモチーフ
- リュートを引き継いだ楽器のシルエット

## 変えた要素

- 2頭身のSD体型から、約7頭身の青年体型へ
- ファンタジー衣装から、ネイビー系のNeo Tokyoテックウェアへ
- リュートを、シアンとライムの回路表現を持つエレキギターへ
- 花びらや音符の演出を、発光ライン・ストラップ・波形のイメージへ

## 位置づけ

これは20体一括生成前のデザイン確認用 `v01`。吟遊詩人型・騎士型・僧侶型に加え、髪色・性別・メガネのバリエーション4体を確認している。髪色や性別はキャラの識別性を高めるための展開要素として扱い、裏モードの役割と象徴アイテムは維持する。この方向性を採用する場合、同じルールで20体それぞれに青年男性版・青年女性版を展開する。
